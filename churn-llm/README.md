# 고객 상담 LLM 실행 코드

설치와 실행 방법은 [저장소 README](../README.md)를 참고하세요. 비교 결과는 [20문항 노트북](notebooks/churn_llm_benchmark20.ipynb)에 내장되어 있습니다. 노트북에서 기본 분석을 실행하려면 `requirements-analysis.txt`의 패키지를 설치하세요.

`runtime/`에는 검색·프롬프트·생성·검사 코드가 있고, `experiments/`에는 비교 실험 코드가 있습니다. 과거 실행 폴더는 로컬 보관 자료이며, 내장 결과만으로 노트북 기본 분석을 실행할 수 있습니다.
