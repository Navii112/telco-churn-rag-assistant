# 시연용 서비스 이용 확인 가이드

실제 장애 처리 매뉴얼이 아닌 가상 상담 준비 지침이다.

## technical | 인터넷과 기술 지원 이용 확인
InternetService가 DSL 또는 Fiber optic인 경우 인터넷 이용 상황을 확인할 수 있다. TechSupport=No는 기술 지원 부가 서비스 미가입을 뜻하며 장애 발생을 뜻하지 않는다. OnlineSecurity=No도 실제 보안 사고가 있었다는 의미가 아니다.
질문: 인터넷 연결이나 속도, 기술 지원 이용과 관련해 확인하고 싶은 점이 있으신가요?
조치: 실제 불편이 접수되면 발생 시점과 증상을 확인하고 실제 운영 절차에 따라 기술 담당자에게 연결한다. 장애가 확인되지 않은 상태에서 장애 원인을 단정하지 않는다.

## no-internet | 인터넷 미가입 고객의 확인 범위
InternetService=No인 경우 인터넷 속도 장애가 있다고 추정하지 않는다. No internet service는 관련 부가 서비스의 미이용 범주이며 데이터 결측이 아니다.
질문: 현재 이용 중인 전화 서비스나 청구 항목에 대해 확인하고 싶은 점이 있으신가요?
조치: 가입하지 않은 인터넷의 장애를 진단하거나 인터넷 추가 가입을 전제로 상담하지 않는다.
