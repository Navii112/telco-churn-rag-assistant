# 시연용 요금과 결제 확인 가이드

포트폴리오용 가상 지침이다. 금액과 요율을 정하는 실제 상품 문서는 아니다.

## billing | 청구 금액과 이용 항목 확인
MonthlyCharges는 월 청구 금액, TotalCharges는 누적 청구 금액이다. 데이터의 단위는 달러이며 원화로 바꾸어 안내하지 않는다. 금액만으로 과다 청구나 불만을 단정하지 않는다. 최근 인상 여부와 세부 청구 항목은 현재 데이터에 없다.
질문: 현재 청구 금액이나 이용하지 않는 서비스 항목 중 확인하고 싶은 부분이 있으신가요?
조치: 실제 청구 명세와 고객이 이용하는 항목을 확인한다. 확인되지 않은 절감액이나 할인율은 제시하지 않는다.

## payment | 결제 방식과 납부 편의 확인
PaymentMethod는 결제 방식이며 미납이나 연체 여부가 아니다. Electronic check라는 입력만으로 결제 실패나 신용 문제를 추정하지 않는다. 자동 결제 전환은 고객 의사와 실제 제공 조건을 확인한 뒤 설명한다.
질문: 현재 결제 방법을 이용하는 데 불편한 점이 있으신가요?
조치: 결제 관련 요청을 확인하되 미납, 연체, 신용 상태를 추측하지 않는다. 결제 정보 변경은 담당자의 확인과 고객 동의 후 진행한다.
